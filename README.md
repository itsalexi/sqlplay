# sqlplay

A local SQL practice playground for PostgreSQL. Endless HOA-style challenges,
graded by comparing your results, in a browser or in the terminal.

- Works with no API key: built-in worlds plus a pattern-based level generator.
- Optional: add an OpenAI key to generate new themed worlds and levels.
- Exam mode: 10-question mock tests with optional timer.

**Status:** in design. See [docs/design.md](docs/design.md).
